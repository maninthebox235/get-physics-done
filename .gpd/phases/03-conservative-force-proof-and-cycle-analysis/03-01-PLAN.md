  <name>Task 1: Derive conservative force proof and compute analytical T=0 cycle</name>
  <files>derivations/conservative_force_proof.tex</files>
  <action>
    Write a formal proof that the Casimir force is conservative for fixed material properties. The derivation must contain:

    1. **Statement of the theorem:** For parallel plates with fixed dielectric response functions epsilon(omega) and mu(omega), the Casimir force F(a, T) = -partial(V)/partial(a) where V is a single-valued potential (the Helmholtz free energy F(a,T) or vacuum energy E(a) at T=0).

    2. **Proof structure:**
       - At T=0: The vacuum energy E_vac(a) is a function of plate separation a only (for fixed geometry and material). Since E_vac is single-valued, F = -dE/da is conservative. Explicitly: E/A = -pi^2/(720 a^3) for ideal plates (Casimir 1948).
       - At finite T: The Helmholtz free energy F(a, T) = -T ln Z(a, T) is a state function. F = -partial(F)/partial(a)|_T is the gradient of a state function at fixed T, hence conservative.
       - The Lifshitz formula gives F(a, T) as a function of a and T only (for fixed epsilon, mu), confirming single-valuedness.

    3. **Explicit conditions for conservativeness (A1-A4):**
       - A1: Fixed material response epsilon(omega), mu(omega) -- independent of plate separation and unchanged during the cycle
       - A2: Quasi-static process -- system in thermal equilibrium at every intermediate step
       - A3: Isothermal process at fixed T, OR material response is T-independent (so T variations do not affect the force law)
       - A4: Fixed geometry class -- plates remain parallel, no topology change

    4. **Corollary -- vanishing cycle work:**
       For any closed path in configuration space (a1 -> a2 -> a1):
       W_net = oint F(a) da = 0 (exact for conservative force)

    5. **Analytical T=0 ideal cycle computation:**
       For a cycle between a_min and a_max:
       - W_close = integral_{a_max}^{a_min} F(a) da = E(a_min) - E(a_max) = (-pi^2/720)(1/a_min^3 - 1/a_max^3) per unit area
       - W_open = integral_{a_min}^{a_max} F(a) da = E(a_max) - E(a_min) = -W_close
       - W_net = W_close + W_open = 0 (exact algebraic cancellation)

       Work out the explicit numerical values for a_min = 100 nm, a_max = 1 um (in natural units: convert via 1 nm = 1e-9 m, and 1 m = 1/(hbar*c) in natural units = 1/197.3e-9 eV^{-1} ... actually, keep everything in meters and use the SI formula, OR work consistently in natural units where a has dimensions of inverse energy).

       For the natural-units calculation: a in meters means a_natural = a_SI / (hbar*c) where hbar*c = 197.3269804e-9 eV*m. But the code uses plate separation directly in natural units where [a] = [length], and the Casimir functions take a in these units. Follow the convention in casimir_ideal.py.

    6. **Explicit statement of what breaks conservativeness:**
       - If epsilon(omega) changes during the cycle (boundary condition change loophole -- Phase 05)
       - If process is non-quasi-static (dynamic Casimir -- Phase 06)
       - If topology changes (cavity creation/destruction -- Phase 05)

    Use LaTeX formatting. Include ASSERT_CONVENTION lines for sign and unit conventions.
  </action>

    4. Sign check: W_close > 0 (plates closing under attractive force = work extracted by external agent receiving energy from Casimir force); W_open < 0 (external agent must input work to pull plates apart). Signs are consistent with F < 0 (attractive).
