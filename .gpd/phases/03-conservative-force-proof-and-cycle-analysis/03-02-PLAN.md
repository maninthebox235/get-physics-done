    **Test configurations:**

    | Config | a_min | a_max | T | Material | Notes |
    |--------|-------|-------|---|----------|-------|
    | 1 | 100 nm | 1 um | 0 K | Ideal | Regression against Plan 03-01 |
    | 2 | 100 nm | 1 um | 300 K | Ideal | Thermal ideal (finite-T Matsubara for perfect conductor) |
    | 3 | 100 nm | 1 um | 300 K | Drude (Au: omega_p=9.0eV, gamma=0.035eV) | Standard Drude gold |

    | 6 | 200 nm | 2 um | 77 K | Drude (Au) | Low temperature |

    For unit conversion: Use the same approach as casimir_lifshitz.py. Temperature in natural units via T_natural = k_B * T_kelvin (using K_B_EV and EV_TO_INV_M from material_models.py). Plate separations in natural units (meters / (hbar*c)).

    **For each configuration, compute:**
    - W_close = integral_{a_max}^{a_min} F(a, T) da (via scipy.integrate.quad)
    - W_open = integral_{a_min}^{a_max} F(a, T) da
    - W_net = W_close + W_open
    - |W_net| / |W_close| (relative precision of cancellation)

    **Integration strategy for Lifshitz force:**
    The Lifshitz force at each a involves a Matsubara sum + momentum integral, making each F(a) evaluation expensive. Use:
    - scipy.integrate.quad with epsrel=1e-12 for the work integral
    - If too slow, use scipy.integrate.fixed_quad with ~100 Gauss-Legendre points
    - Alternative: since F = -dF_free/da, can also compute W = F_free(a_min) - F_free(a_max) if a free energy function is available. Check if casimir_lifshitz.py provides an energy/free energy function.

    **Optimization note:** For the ideal finite-T case (Config 2), the force is the same as summing Matsubara terms for the perfect conductor. For configs 3-6, each quadrature point calls lifshitz_force which internally does a Matsubara sum. Budget ~30 seconds per configuration.

    2. `test_wnet_ideal_300K`: Config 2 has |W_net|/|W_close| < 1e-10

    8. `test_wopen_negative`: W_open < 0 for all configs (must push against attraction)

    If |W_net|/|W_close| > 1e-10 for any configuration, this triggers the STOP condition from the roadmap. Debug the integration before proceeding -- the result should be exactly zero for a conservative force, so any nonzero W_net is numerical error.

    **Energy budget for each configuration:**

    For a closed isothermal cycle with conservative force:
    - W_net = 0 (conservative force)
    - Delta_E_vac = 0 (cycle returns to initial state)
    - Delta_S = 0 (state function returns to initial value)
    - Q = T * Delta_S = 0 (no net heat exchange)
    - Energy conservation: W_net = Delta_E_vac + Q => 0 = 0 + 0

    The energy conservation check is: |W_net - (Delta_E_vac + Q)| / |W_close| < 1e-8.
    Since Delta_E_vac = Q = 0 for closed cycles, this reduces to |W_net| / |W_close| < 1e-8, which is satisfied by the 1e-10 requirement from Task 1.
