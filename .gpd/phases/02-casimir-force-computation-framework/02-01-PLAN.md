  <name>Task 1: Implement ideal Casimir force (analytical + mode summation)</name>
  <files>code/casimir_ideal.py</files>
  <action>
    Create `code/casimir_ideal.py` implementing the T=0 ideal parallel-plate Casimir force.

    Two independent computation paths:

    1. **Analytical formula (reference):**
       - `casimir_force_ideal(a)`: Returns F/A = -pi^2 / (240 * a^4) in natural units
       - `casimir_energy_ideal(a)`: Returns E/A = -pi^2 / (720 * a^3)
       - These are the EXACT results serving as benchmark targets.

    2. **Mode summation with zeta regularization:**
       - `mode_sum_zeta(a, s=-3)`: Compute vacuum energy via E/A = (1/2) sum_modes omega_n
         with zeta regularization (analytically continue the sum).
       - The electromagnetic modes between perfect conducting plates at separation a have
         transverse momenta k_perp and quantized k_z = n*pi/a (n = 1, 2, ...).
       - Vacuum energy per unit area: E/A = (1/(2*pi)) integral dk_perp k_perp sum_{n=1}^{inf} sqrt(k_perp^2 + (n*pi/a)^2)
       - After integration over k_perp and zeta regularization of the n-sum, this yields
         E/A = -(pi^2)/(720 a^3) times a factor from Riemann zeta: zeta(-3) = 1/120.
       - Use mpmath for arbitrary-precision evaluation to ensure < 10^{-6} accuracy.
       - Include factor of 2 for two polarizations of the EM field.

    3. **Numerical mode sum (cross-check):**
       - `mode_sum_numerical(a, n_max=1000, k_max=100/a, n_k=1000)`: Direct numerical
         summation with exponential regulator exp(-alpha * omega) and alpha -> 0 extrapolation.
       - This provides an independent numerical check that does NOT rely on zeta function identities.
       - Use Richardson extrapolation or polynomial fit in alpha to extract the alpha->0 limit.

    Include at top of file:
    ```python
    # ASSERT_CONVENTION: natural units (hbar=c=k_B=1)
    # ASSERT_CONVENTION: F < 0 for attractive Casimir force
    # ASSERT_CONVENTION: [F/A] = length^{-4}, [E/A] = length^{-3}
    ```

    Use mpmath for arbitrary-precision arithmetic where needed.
    Use numpy for vectorized operations in the numerical cross-check.
  </action>
  <verify>
    1. Dimensional analysis: casimir_force_ideal(a) has units [a]^{-4} — verify by checking F(2a)/F(a) = 1/16
    2. Sign: F/A < 0 for all a > 0 (attractive force convention)
    3. Scaling: F/A ~ a^{-4} — verify power law exponent numerically
    4. Energy-force relation: F/A = -d(E/A)/da — verify numerically at a = 100 nm, 1 um
    5. Mode sum vs analytical: |mode_sum_zeta(a) - casimir_energy_ideal(a)| / |casimir_energy_ideal(a)| < 10^{-10}
    6. Numerical mode sum: after alpha->0 extrapolation, agrees with analytical to < 10^{-4} (less precise but independent method)
  </verify>
  <done>Three computation paths implemented (analytical, zeta mode sum, numerical mode sum), all agreeing on F/A = -pi^2/(240 a^4) to stated precisions</done>
