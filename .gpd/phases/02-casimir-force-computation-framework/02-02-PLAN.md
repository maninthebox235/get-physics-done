  <name>Task 1: Implement Lifshitz formula with general reflection coefficients</name>
  <files>code/casimir_lifshitz.py</files>
  <action>
  Create `code/casimir_lifshitz.py` implementing the Lifshitz formula:

  ```
  F/A = -(k_B T / pi) * sum'_{l=0}^{l_max} integral_0^infinity dk_perp * k_perp * kappa_0
        * sum_{P=TE,TM} r_P^2 * exp(-2*kappa_0*a) / (1 - r_P^2 * exp(-2*kappa_0*a))
  ```

  Key components:
  1. `reflection_TE(kappa_0, kappa, epsilon)`: TE reflection coefficient
  2. `reflection_TM(kappa_0, kappa, epsilon)`: TM reflection coefficient
  3. `matsubara_sum(a, T, epsilon_func, l_max=None)`: Matsubara frequency sum
     - Automatic l_max determination: truncate when |contribution| < 10^{-12} * |max contribution|
     - l=0 term with half weight (primed sum convention)
  4. `lifshitz_force(a, T, epsilon_func)`: Full Lifshitz force per unit area
  5. `lifshitz_force_T0(a, epsilon_func)`: T=0 limit (sum → integral)

  The epsilon_func parameter is a callable epsilon(ixi) for material response.

  Include convention assertions at top:
  ```python
  # ASSERT_CONVENTION: natural units (hbar=c=k_B=1)
  # ASSERT_CONVENTION: F < 0 for attractive
  # ASSERT_CONVENTION: primed sum: l=0 term carries half weight
  ```

  Use scipy.integrate.quad for k_perp integration.
  Use numpy for vectorized operations within each Matsubara term.
  </action>
  <verify>
  1. With epsilon(ixi) = infinity (perfect conductor), lifshitz_force_T0(a) matches casimir_force_ideal(a) to < 10^{-6}
  2. Dimensional analysis: [F/A] = [T] * [length^{-2}] * [length^{-1}] = [length^{-4}] ✓
  3. Sign: lifshitz_force returns F/A < 0 for all a > 0
  4. Matsubara sum converges (l_max is finite and reasonable: typically 100-1000 at room T)
  </verify>
  <done>Lifshitz formula implemented with general reflection coefficients; perfect conductor limit recovers ideal Casimir result to < 10^{-6}; Matsubara sum converges reliably</done>
