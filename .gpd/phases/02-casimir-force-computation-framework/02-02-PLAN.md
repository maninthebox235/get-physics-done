  <name>Task 1: Implement Drude/plasma material models and reflection coefficients</name>
  <files>code/material_models.py</files>
  <action>
    Create `code/material_models.py` implementing dielectric response functions at imaginary frequencies and Fresnel reflection coefficients for the Lifshitz formula.

    Include at top of file:
    ```python
    # ASSERT_CONVENTION: natural units (hbar=c=k_B=1)
    # ASSERT_CONVENTION: [omega_p] = [gamma] = [length^{-1}] in natural units
    # ASSERT_CONVENTION: Reflection coefficients for semi-infinite dielectric slab
    ```

    **Unit conversion:**
    - `ev_to_natural(E_eV)`: Convert energy in eV to natural units (inverse meters).
      1 eV = 1 / (hbar * c) in inverse length. With hbar*c = 197.3269804 MeV*fm,
      1 eV = 5.067730759e6 m^{-1}.

    **Dielectric functions (evaluated at imaginary frequency ixi):**

    1. `epsilon_drude(xi, omega_p, gamma)`:
       Returns 1 + omega_p^2 / (xi * (xi + gamma)) for xi > 0.
       At xi=0: return np.inf (metallic screening).

    2. `epsilon_plasma(xi, omega_p)`:
       Returns 1 + omega_p^2 / xi^2 for xi > 0.
       At xi=0: return np.inf.

    3. `make_drude(omega_p, gamma)`: Returns callable epsilon(xi).
    4. `make_plasma(omega_p)`: Returns callable epsilon(xi).

    **Gold parameters:**
    ```python
    GOLD_OMEGA_P_EV = 9.0
    GOLD_GAMMA_EV = 0.035
    GOLD_OMEGA_P = ev_to_natural(9.0)    # m^{-1}
    GOLD_GAMMA = ev_to_natural(0.035)    # m^{-1}
    ```

    **Reflection coefficients:**

    5. `reflection_TE(kappa_0, kappa)`:
       r_TE = (kappa_0 - kappa) / (kappa_0 + kappa)

    6. `reflection_TM(kappa_0, kappa, epsilon)`:
       r_TM = (epsilon * kappa_0 - kappa) / (epsilon * kappa_0 + kappa)

    7. **l=0 special case functions** (crucial for Drude-plasma controversy):

       `r_TE_l0_drude(k_perp, omega_p, gamma)`: Returns 0.
       Physical reason: As xi->0, both kappa and kappa_0 -> k_perp, so r_TE -> 0.

       `r_TE_l0_plasma(k_perp, omega_p)`:
       Returns (k_perp - sqrt(k_perp^2 + omega_p^2)) / (k_perp + sqrt(k_perp^2 + omega_p^2)).
       This is nonzero -- it is the essential Drude vs plasma distinction.

       `r_TM_l0(k_perp)`: Returns 1 for both models (metallic screening).

    8. `compute_kappas(k_perp, xi, epsilon_val)`:
       Returns (kappa_0, kappa) = (sqrt(k_perp^2 + xi^2), sqrt(k_perp^2 + epsilon_val * xi^2)).

    All functions must accept numpy arrays for k_perp to enable vectorized integration.
  </action>
  <verify>

    2. epsilon_drude(xi) > 1 for all xi > 0

    4. |r_TE| <= 1 and |r_TM| <= 1 for all physically valid inputs
    5. epsilon=1 (vacuum): r_TE = r_TM = 0
    6. epsilon->infinity: |r_TE| -> 1, |r_TM| -> 1

    9. Both l=0: r_TM = 1
    10. Gold omega_p = 9.0 eV ~ 4.56e7 m^{-1} (order of magnitude)
  </verify>

<task type="auto">
  <name>Task 2: Implement Lifshitz formula and structural test suite</name>
  <files>code/casimir_lifshitz.py, code/tests/test_lifshitz_structure.py</files>
  <action>
    Create `code/casimir_lifshitz.py` implementing the Lifshitz formula.

    Include at top:
    ```python
    # ASSERT_CONVENTION: natural units (hbar=c=k_B=1)
    # ASSERT_CONVENTION: F < 0 for attractive Casimir force
    # ASSERT_CONVENTION: Matsubara primed sum: l=0 term has half weight
    # ASSERT_CONVENTION: [F/A] = [length^{-4}]
    ```

    The Lifshitz formula:
    F/A = -(T/pi) * sum'_{l=0}^{l_max} integral_0^{infinity} dk_perp * k_perp * kappa_0
          * sum_{P=TE,TM} [ r_P^2 * exp(-2*kappa_0*a) / (1 - r_P^2 * exp(-2*kappa_0*a)) ]

    Key functions:

    1. `matsubara_frequencies(T, l_max)`:
       Returns array xi_l = 2*pi*l*T for l = 0, 1, ..., l_max.

    2. `lifshitz_integrand(k_perp, a, xi_l, epsilon_val, is_l0=False, material_type='drude', omega_p=None, gamma=None)`:
       - Compute kappa_0, kappa via compute_kappas
       - Compute r_TE, r_TM (use l=0 special functions when is_l0=True)
       - Return k_perp * kappa_0 * sum_P [ r_P^2 * exp(-2*kappa_0*a) / (1 - r_P^2 * exp(-2*kappa_0*a)) ]

    3. `matsubara_term(l, a, T, epsilon_func, material_type='drude', omega_p=None, gamma=None)`:
       - xi_l = 2*pi*l*T
       - Integrate lifshitz_integrand over k_perp from 0 to infinity
       - Use scipy.integrate.quad; recommend substitution u = k_perp * a for stability
       - Return the integral value

    4. `lifshitz_force(a, T, epsilon_func, material_type='drude', omega_p=None, gamma=None, l_max=None)`:
       - F/A = -(T/pi) * sum'_{l=0}^{l_max} matsubara_term(l, ...)
       - Primed sum: l=0 term multiplied by 1/2
       - Auto l_max if None: increase until |term(l)| < 10^{-12} * |term(1)|
       - Return F/A (negative for attractive)

    5. `lifshitz_force_T0(a, epsilon_func=None, material_type='perfect')`:
       - T=0 limit: sum -> integral
       - F/A = -(1/(2*pi^2)) * integral_0^inf dxi integral_0^inf dk_perp k_perp kappa_0 sum_P [...]
       - For perfect conductor: r_TE = -1, r_TM = 1, both give r_P^2 = 1
       - Use scipy.integrate.dblquad or nested quad

    Then create `code/tests/test_lifshitz_structure.py`:

    1. **test_reflection_coefficient_limits**: All limits from Task 1 verify section.

    2. **test_drude_gamma_zero**: epsilon_drude with gamma ~ 0 matches epsilon_plasma to < 10^{-10}.

    3. **test_matsubara_convergence**: At T=300K (T_nat = 300 * k_B = 300 * 8.617e-5 eV -> natural), a=1um, verify partial sums converge.

    4. **test_matsubara_half_weight**: Verify l=0 term enters with factor 1/2 by comparing lifshitz_force output against manually computed first-few-terms sum.

    5. **test_sign_convention**: lifshitz_force returns F/A < 0 at T=300K, a=1um for Drude gold.

    6. **test_vacuum_gives_zero**: With epsilon=1, r=0, so F=0.

    7. **test_dimensional_scaling_T0**: At T=0 with perfect conductor, F(2a)/F(a) = 1/16 (a^{-4} scaling).

    Note: matplotlib is NOT available. All tests use numerical assertions only.
  </action>
