  <name>Task 1: Build parameter sweep module and run coarse validation</name>
  <files>code/parameter_sweep.py, data/sweep/coarse_validation.npz</files>
  <action>
    Create code/parameter_sweep.py with the following components:

    1. **Grid generation function** `generate_grid(n_amin, n_amax, n_T, amin_range, amax_range, T_range)`:
       - a_min: 100 points logarithmically spaced in [10e-9, 1e-6] meters
       - a_max: 100 points logarithmically spaced in [100e-9, 10e-6] meters
       - T: 50 points linearly spaced in [0, 300] K, with T=0 as first point
       - Return 3D meshgrid arrays + boolean mask where a_min < a_max
       - For the coarse grid: use n_amin=20, n_amax=20, n_T=10

    2. **Single-point sweep function** `compute_point(a_min, a_max, T_K, material)`:
       - Convert T from Kelvin to natural units: T_nat = T_K * 436.7 [m^{-1}/K] (but use exact k_B/(hbar*c) from scipy.constants)
       - For material='ideal' and T=0: use cycle_work_ideal_analytical(a_min, a_max)
       - For material='ideal' and T>0: use cycle_work_lifshitz with material_type='perfect'
       - For material='drude': use cycle_work_lifshitz with epsilon_drude, omega_p=9.0eV, gamma=0.035eV (convert to natural units via /hbar*c)
       - For material='plasma': use cycle_work_lifshitz with epsilon_plasma, omega_p=9.0eV, gamma=0
       - Return dict with keys: W_close, W_open, W_net, eta (= |W_net|/|W_close| if |W_close| > 0 else 0)
       - Handle edge case: if a_min >= a_max, return NaN values

    3. **Parallel sweep function** `run_sweep(grid_amin, grid_amax, grid_T, mask, material, n_workers=None)`:
       - Use concurrent.futures.ProcessPoolExecutor
       - Distribute valid (masked) grid points across workers
       - Collect results into numpy arrays matching grid shape
       - Invalid points (mask=False) filled with NaN
       - Return dict of result arrays: W_close, W_net, eta (each shape matching grid)
       - Print progress every 10% of points

    4. **Result storage**: Save coarse sweep results to data/sweep/coarse_validation.npz containing:
       - Grid arrays: a_min_grid, a_max_grid, T_grid, valid_mask
       - For each material: {material}_W_close, {material}_W_net, {material}_eta

    5. **Coarse validation script** (as __main__ block or separate function `run_coarse_validation()`):
       - Generate coarse grid (20x20x10)
       - Run sweep for ideal (T=0 slice only), Drude (all T), plasma (all T)
       - Report: max(eta) per material, number of valid points, any points with eta > 1e-10
       - Save to data/sweep/coarse_validation.npz

    IMPORTANT: Use exact constants from scipy.constants for unit conversions. Do NOT hardcode approximate values.
    IMPORTANT: The existing cycle_work_lifshitz returns (W_close, W_open, W_net). W_net is always exactly 0.0 by construction (conservative force). The diagnostic eta = |W_net|/|W_close| tests this.
    IMPORTANT: For ideal plates at T=0, cycle_work_ideal_analytical returns (W_close, W_open, W_net) where W_net = 0 exactly.

    Include ASSERT_CONVENTION block at top of file verifying natural units and sign conventions.
  </action>
